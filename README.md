# Río Amigo

Aplicación web progresiva (PWA) para navegación y pesca deportiva en la cuenca del Plata.

## Instalación en el celular

1. Abrir el link de la app en Chrome (Android) o Safari (iPhone)
2. Menú del navegador → "Agregar a pantalla de inicio"
3. Aparece el ícono como una app nativa

## Desarrollo

Es una PWA estática. No requiere build. Vercel la publica tal cual.

Archivos:
- `index.html` — la app completa
- `manifest.json` — datos para instalación
- `sw.js` — Service Worker (modo offline)
- `icon-192.png`, `icon-512.png` — íconos
